# xampp

Repositório criado para facilitar a localização do pacote do XAMPP para os alunos da Etec Adolpho Berezin
Passos para utilizar:

1 - Abra o CMD

2 - Digite CD\ e pressione Enter

3 - Confirme que o cursos está na unidade C:\

4 - Digite git clone https://github.com/etecab/xampp.git e pressione Enter

5 - Acesse a pasta XAMPP e clique com o botão direito do mouse no xampp-control para iniciar o XAMPP em Modo Administrador
